# Clash Config Gen 设计系统

> **V2 · Signal Flow Workspace · 2026-07-22**
>
> UI/UX Pro Max 的检索结果将该产品归为开发者工具；本项目明确采用冷白与蓝青科技风，覆盖其默认深色推荐。界面以真实配置状态、可读工作流和可信表单为主，不使用紫色 AI 模板、黑色大模块、霓虹边框或夸张玻璃拟态。

## 产品定位

- **产品**：Clash / OpenClash / mihomo 订阅配置生成与发布工作台。
- **核心用户任务**：导入节点 → 整理节点 → 配置分流 → 检查草稿 → 发布订阅。
- **设计目标**：让用户始终理解当前草稿、检查状态和发布差异；视觉服务于安全感与可操作性，不伪造节点数量、延迟或运行数据。

- 背景网格、光晕和连接线的对比度低于内容层，不承载信息。

## 字体、间距与形状

- 标题：`Space Grotesk, Manrope, PingFang SC, system-ui`；正文：`Manrope, PingFang SC, Microsoft YaHei, system-ui`；数据与技术标识：`DM Mono, JetBrains Mono, monospace`。
- 标题层级：页面主标题 38–62px，面板 18–24px，正文 14–16px，技术辅助文字 11–12px。
- 4px 间距体系：4、8、12、16、18、24、32、48、64；桌面页面边距 32px，移动端 16px。
- 圆角：控件 12px、卡片 18px、主要工作面板 26px；不使用夸张的药丸式布局。
- 阴影：卡片 `0 18px 46px rgb(37 92 151 / 11%)`，浮层 `0 26px 76px rgb(24 86 154 / 17%)`；只用于层级，不制造“漂浮的玻璃”。

## 组件规则

### 按钮与输入

- 主要操作：蓝青渐变、白字、最小高度 44px；次要操作：白底、蓝灰边框。
- Hover 仅使用 1px 位移、边框/阴影变化；disabled 必须降低对比并禁用交互。
- 输入框使用可见 Label、白底、蓝灰边框和 3px 焦点环；错误信息贴近字段并明确给出恢复路径。

### 导航与工作流

- 桌面端使用固定侧栏；移动端保留 Streamlit 原生折叠控制，作为抽屉入口，不能横向溢出。
- 五个工作区始终映射到真实功能：控制台、导入节点、节点管理、分流规则、生成与检查。
- 四阶段流程可视化只显示真实节点数、检查结果与发布差异；来源元数据不作为用户界面概念展示。当前步骤使用浅蓝/浅青底和连接信号线。

### 卡片、表格与状态

- 统计卡只展示真实草稿统计；发布差异使用等宽数字。
- 节点卡片以名称、服务器、协议和状态构成；左侧 44px 拖动把手支持排序，并提供 `Alt + ↑/↓` 键盘替代。
- 编辑器直接展开在当前节点卡片内，不使用脱离上下文的页面底部编辑区。
- 分流规则遵循渐进披露：预设规则目标、单条规则、新规则集和规则集详情默认折叠。
- 成功、警告、失败和草稿状态分别使用 `--ccg-success`、`--ccg-warning`、`--ccg-danger` 与蓝色提示；所有状态都有文本说明。

### 登录、弹层与页脚

- 品牌标记使用四个端点与双向汇流路径，表达“节点输入 → 规则编排 → 配置输出”；以项目内联 SVG 呈现，不依赖外部图标服务。
- 登录页左侧展示真实能力和三步流程，标题使用无标点的上下双行结构，右侧为带明确安全说明的表单；不显示虚构指标。
- 现有 Streamlit expander、提示、文件上传与确认行为保持不变，只统一边框、圆角和层级。
- 页脚使用细分隔线和轻量状态点，显示真实项目文档、Mihomo 帮助、Docker/mihomo 校验构建信息和会话提示；不虚构公司、备案、隐私链接或版本号。

## 动效与无障碍

- 动效密度为 7/10：使用低频数据光线、节点脉冲、分层入场和背景光晕；只动画 `opacity`、`transform`、`background-position`。
- 流程与状态动效不阻塞操作；悬浮和按钮反馈为 150–200ms。
- `@media (prefers-reduced-motion: reduce)` 下关闭非必要动效和过渡。
- 焦点环至少 3px；文本对比度达到 WCAG AA；所有表单保持 label、键盘 Tab 顺序和可读状态文本。

## 响应式断点

| 宽度 | 规则 |
| --- | --- |
| >= 1200px | 宽工作台、四阶段一行、节点/发布双栏 |
| 761–1199px | 保留侧栏和工作流，节点表缩减协议列 |
| <= 760px | 侧栏使用折叠抽屉；工作流 2×2；表单单列；页脚纵向换行 |
| <= 375px | 保持 16px 边距与 44px 控件；不出现页面横向滚动 |

## 不变功能契约

- 不修改 FastAPI 路由、认证 Cookie、SQLite 数据、订阅 Token、规则集文件、节点解析、mihomo 检查或发布逻辑。
- 保留导航状态、复制订阅链接、Token 重置、管理员用户管理、全局设置、导入、节点编辑、规则配置、草稿检查和发布流程。
- 来源名称和来源列表仅从界面隐藏；历史 `_source_id`、`_source_name` 与 `import_sources` 继续保存，保证旧草稿和数据结构兼容。
- 不会插入测试账号、密码、虚构指标或假数据。
